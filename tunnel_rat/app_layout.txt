# Tunnel R.A.T. app layout
#
# Applied at build time by scripts/fbt/appmanifest.py, for both the bundled
# Momentum apps (applications/external) and applications/tunnel_rat_apps.
# Lets you move or drop an app without editing its application.fam (or the
# Momentum-Apps submodule).
#
#   <appid>   <folder>    install the app to /ext/apps/<folder> instead
#   <appid>   REMOVE      don't build or ship it
#
# A line whose appid matches no app stops the build, so typos can't slip by.
# Don't move apps the firmware opens by a fixed path: picopass, mfkey,
# mass_storage, subghz_remote, subghz_playlist, proto_pirate, ir_remote,
# xremote, wav_player, magspoof, text_viewer, hex_viewer, nightstand, and
# anything in apps/assets.
